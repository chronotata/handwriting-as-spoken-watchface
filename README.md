# Handwritten As Spoken

## Background

A watchface for the Pebble Time 2, inspired by various "written" watchfaces,
but mainly building off an implemention, **[Handwritten](https://github.com/etiennovski/Handwritten)**
by **[etiennovski](https://github.com/etiennovski)**.

I have always wanted a written watchface that tells the time "traditionally"
as if reading from an analogue clock, as I have always liked thinking of time
as relative to the closest hour mark, rather than reading off the hour and
minute numbers. Others have built on similar concepts but none in the way that I really like.
Thanks to modern LLM it is a lot easier to implement this with
my low experience in writing these types of apps, so this watchface was
developed extensively with the help of AI coding agent (Claude)

All handwriting texts are made by me and the layouts are hand-tuned. AI use
is limited to technical implementations and documentation. Codes are reviewed
by me before committing

I am uploading this to GitHub mainly to help with version control, as I am
planning to make further design changes and features additions. Texts below
this line are generated by AI with small human changes

_________________________________

A Pebble watchface for the **Pebble Time 2** that tells the time the way
it's actually said out loud — *"quarter past three"*, *"twenty-nine minutes
to midnight"*, *"half past seven"* — handwritten across the screen, one
word at a time, rather than reading digits off a clock face.

## Features

- **Traditional time-telling** — *past*/*to* the hour, *quarter*,
  *half*, *midnight*/*midday*/*noon* used the way people actually say them
  (not simply mirroring the 12/24-hour setting)
- **Three ways to read the minute** — the exact minute, the nearest five
  the way an analogue dial is usually read aloud, or the nearest five with
  *just gone* / *nearly* saying which way it rounded.
- **Three ways to say `minute(s)`** with the exact minute — only when the
  minute isn't a round five, never, or after any number (but never
  *"quarter minutes past"*). Rounding makes every minute a round five, so the
  setting greys out when either rounded mode is on.
- **A date line** in two formats — `21st Aug. 2026` or `Mon. 21st Aug.` —
  always centred, ordinal correctly superscript.
- **A handwriting-style reveal animation** — words appear to be written on,
  left to right, and only the parts of the display that actually changed
  redraw on each minute tick. Words that leave with nothing in their place
  are **rubbed out right to left** rather than blinking out.
- **Fifteen live tuning sliders**, tucked behind a collapsed *Fine tuning*
  section in the watch's settings — nudge any row up or down by eye, no
  rebuild required. A slider that cannot affect anything under the current
  settings is greyed out, and tapping a slider track does nothing, so
  scrolling past one can't move it by accident.
- **Paper and ink colours** configurable from the same page, with a stroke
  weight that compensates for dark text rendering thinner than light text
  on this panel.

## Status

**Complete, in the maintainer's own handwriting.** All 83 words are drawn by
hand and running on a real Pebble Time 2.

Emery (Pebble Time 2, 200×228) is the only target platform; the layout is
built around that screen, and other Pebble hardware is not planned.

## Building it yourself

The watchface can be built in either of two typefaces — one per build:

- **The handwriting** (the default): the 83 word images drawn by hand.
- **A rendered font**: `python3 tools/tune.py --font`. Every word is drawn
  from the bundled TTF instead, and no handwriting is needed at all.

To use **your own handwriting**, `tools/make_templates.py` produces PDF
pages with a box for every word. Draw over them on a tablet, export, and
`tools/extract_handwriting.py` turns the pages back into watchface images.
The pipeline was built around a **Supernote Nomad**, and relies on its
exports keeping the ink as a separate layer over the page — a printed and
scanned page will not work as-is. Until every word is drawn, build with
`--font`.

Full step-by-step instructions, including fixes for every WSL/Ubuntu
gotcha likely to come up along the way, are in **[UPGRADING.md](UPGRADING.md)**.

For how the code is put together and why — the layout engine, the
image-based rendering approach, the tuning constants — see
**[CONTEXT.md](CONTEXT.md)**.

## Origins and credit

This project began as a rewrite of **[Handwritten](https://github.com/etiennovski/Handwritten)**
by **[etiennovski](https://github.com/etiennovski)** — the original concept
of a Pebble watchface that spells out the time in handwriting, word by
word, is entirely theirs, going back to 2014.

Almost nothing of the original implementation remains: the wording engine,
the layout and animation system, and the C source are all new, and the
original's hand-drawn word images have been replaced by new ones, drawn by
the maintainer. If you're looking for the original hand-drawn artwork and
the classic Pebble-generation build, that's the repository to go to.

The original repository does not carry an explicit license file, so if
you're planning to build on *this* fork for anything beyond personal use,
it's worth reaching out to the original author first — this repo's own
license (below) only covers what's new here.
